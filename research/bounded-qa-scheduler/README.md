# Bounded fixed QA scheduler

Base: accepted PR #192, fc850b673616f3eb6e4cefef8346517722f2ee2c; controller QA 45531071508 (27 controller and 11 PC presence tests, hosted fixed CPU acceptance), full regression 45531071617 passed.

This is a one-shot local admission policy, not a deployed recurring scheduler. An operator supplies an independently retained SHA-256 anchor for an exact revision-bound plan and a UTC epoch-second half-open admission window of at most one hour. The policy is bound durably; before the window the queue remains empty; after the window a missed plan is terminal with no catch-up. Admission creates exactly three fixed queue entries atomically, including the blocked GPU entry, and cannot repeat across concurrent polls or restart. Cancellation before admission is terminal. Direct service enqueue is refused for a schedule-bound queue. Existing direct storage access is trusted administrative access and not protected against a compromised host. Receipt intake is unchanged and remains unverified.

Nine scheduler tests include isolated backup/restore, concurrency, missed windows, clock rollback, authorization, tampered plan and direct enqueue denial. The hosted acceptance harness supplies a disposable QA plan and exercises the actual CPU producers over loopback TLS; its locally computed anchor is test evidence, not an independent production approval. The window controls admission, not an execution deadline. Already admitted jobs follow existing lease policy. No recurring campaigns, automatic network polling, external provider requests, physical PC connection, production scheduling, prediction, deployment or publication. Recovery candidates must not be promoted without independent chronology and authorization. Research UNVALIDATED; publication and production dispatch BLOCKED.
