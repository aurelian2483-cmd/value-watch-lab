Written before Phase 2 candidate scores are computed. This is a within-session analysis lock, not a public preregistration. All 76 Phase 1 outcomes have already been viewed. No split of these races is described as untouched.

- Reuse Phase 1 76-race/730-runner input and 16-variant results; do not rerun the 16 masks. Only verify archived full-model baseline agreement as a reproduction check.

- A: remove distance only.

- C: original full-context prior0/2/5/10.

- Structural replacement S1: replace numeric finishing fraction (N-position)/(N-1) with symmetric midpoint plotting position (N-position+.5)/N; known nonfinishers stay0. This endpoint regularisation is a modelling hypothesis, not a fitted likelihood or proved field-strength correction.
