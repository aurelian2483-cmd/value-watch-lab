# Racing reliability improvements — 5 November 2026

## Result corrections

Already scored provisional results are eligible for rechecks every six hours within 48 hours of scheduled start. New results and rechecks share a bounded fair queue. First scores remain unchanged in the ledger; hash-chained amendments record replacement, withdrawal and restoration. Current metrics use the latest supported state. A failed source request is visibly flagged rather than presented as a new outcome. A source that no longer supports the frozen field causes withholding. Late changes outside the recheck window still require review.

## Evidence recoverability

Raw workflow source artifacts are retained for 90 days rather than 30. Permanent append-only receipts record available matching source digests and capture metadata. Missing historical source bytes are disclosed, not re-created or fetched retrospectively. Public receipt metadata does not redistribute full publisher pages or private API payloads. This is improved bounded recoverability, not permanent preservation of all original source bytes or independent timestamp attestation.
