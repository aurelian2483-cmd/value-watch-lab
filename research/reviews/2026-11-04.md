## Corrected defects

1. The refresh timer redrew old memory without fetching new feeds. Periodic and foreground fetches now run with a timeout and a single in-flight request; older replacements are rejected.
2. A redraw collapsed evidence panels and lost keyboard focus. Unchanged cards remain intact; updated cards restore open details and focused controls.
3. Tennis/NFL could survive beyond freshness limits after initial page load. Their ages and probability/identity controls are now evaluated at render time.
4. Long collection runs used the start-of-run clock to decide whether an event was still pre-event. Final collection/archive time now determines eligibility, including a final five-minute cutoff after both sports finish.
5. An isolated collector failure discarded the other sport or could blur freshness. Valid previous data is retained only within its own freshness window, with original timestamps and explicit collection errors.
6. NFL training completeness only checked combined row count. The previous season now requires 272 unique completed regular-season games, 32 teams and 17 appearances per team. Non-finite, negative and fractional scores are rejected.
7. The NFL full slate did not meet the agreed shortlist objective. The five-candidate default is explicitly research-only, with PASS for qualified bets when verified prices and defensible EV are absent.
8. Existing football results were hidden from the main Results page. Source-backed finals are now visible; missing embedded forecast-vector validation is stated explicitly.
9. Legacy workflows concatenated paginated JSON objects then parsed them as one object. Four readers now request a JSON array via `gh api --paginate --slurp`. Production inventory parsing was exercised with two-page fixtures.
10. Failed producer runs uploaded partial diagnostic archives under forecast artifact names. Inventory readers now verify the producer run identity/conclusion and explicitly exclude non-successful runs; successful archives still undergo all original integrity checks. The main dispatcher pins the reviewed reusable workflow revision.
11. Unknown forum/tipster stance defaulted to support. It now counts as a mention, so malformed input cannot manufacture backing.
12. Horse collector metadata incorrectly claimed that no model was implemented. Raw observations now explicitly point to the separate model feed.
13. Horse workflow path triggers omitted collector dependencies. Discovery, reference, secondary-source scripts and tests now trigger the job.
14. The All collected races filter could leak into Upcoming All sports. Changing sport resets that filter to Upcoming and synchronises the control.

## Evidence and limitations

- Local Python and JavaScript control suites passed before publication; browser checks covered the five-row NFL shortlist, 15-row full slate and 12 football result records.
- Actual-source Tennis/NFL collection completed with no collection errors. The reviewed source snapshot contained 35 tennis events (30 supported forecasts) and 15 NFL events (15 supported forecasts); time filtering can reduce visible counts as events start.
- Previous NFL season coverage was source-observed, not independently verified.
- The horse baseline has 13 scored races: too few to establish a generalisable edge. The contextual challenger was worse on its held-out comparison and remains unpromoted.
- Tennis/NFL automatic settlement and prospective performance evaluation are NOT IMPLEMENTED. Snapshots are archived, but archive presence alone is not scored validation.
- Tennis Elo uses separate ATP/WTA histories from January of the current year, so ratings reset annually; it does not model surface, fitness or fatigue. NFL coverage is regular-season only and omits home advantage, quarterback/injury/weather and spread modelling.
- Horse coverage remains partial, source-observed prices may change, and independently executable odds/positive EV are not established.
- The horse advice board contains selected manually captured columns/forum nominations, not an automatic live consensus feed. Chat reports also require explicit publication; new chat text is not automatically copied to the website.
- GitHub schedules may be delayed. Refreshing the browser cannot force a collector to publish a new source snapshot.
