# Phase 69 | Free, no-registration sport sources

Reviewed **21 November 2026** (UK). This decision supersedes the Phase 68 paid and credential-based options for this milestone. No keys, registrations, trials or purchases were used. Existing repository snapshots remain visible with their original evidence tier, timestamp and failure or freshness handling. Their presence does not establish reuse rights for a new integration. See the [coverage inventory](all-sports-coverage.md).

## Main-site coverage and provider decisions

Every sport has an experimental research lane on the homepage and in Paper Lab. The overview distinguishes discovery and directory lanes from counts of timed fixtures. Each lane says that current odds from approved free sources are unavailable. Older price evidence retains its existing provenance and restrictions. The lane descriptions do not trigger provider requests or create evidence.

## Direct probes and boundaries

- **OpenLigaDB.** A single anonymous GET to the documented historical [match endpoint](https://api.openligadb.de/getmatchdata/39738) returned HTTP 200. Match ID `39738`, participant IDs `7` and `40`, competition `bl1`, and kickoff `2016-11-19T17:30:00Z` were present. `lastUpdateDateTime` lacked an offset. SHA-256 of the exact response bytes was `243d3c8f382535391f5338b3baacf592764cf5bee77f713ddc5beaac1a8f3a45`. This confirms connectivity and shape for one historical example and establishes neither current coverage nor an independent result.
- **Cricsheet.** One anonymous GET of the [documented recently-added JSON ZIP](https://cricsheet.org/downloads/recently_added_2_json.zip) returned HTTP 200 on 21 November at 12:41 UTC. It contained 48 JSON files. Example `1525661.json` had five match dates, 27–31 October 2026, and a date-only creation field. SHA-256 of the ZIP was `4abd6e993a01dbb000770867553e3348efd0c952f9b44514d6d7c798d220d6ba`. This probe establishes neither a polling allowance nor a coverage denominator.
- The remaining checks were for public terms, schema, release metadata or human-facing entry points. Restricted or unverified data endpoints were not called. Neither probe payload entered the repository, browser, model, published result feed or private forecasting intake.

No source cleared every connector requirement. No new real forecast or verified outcome became eligible. **UNVALIDATED / BLOCKED.** The strongest next candidate is a bounded OpenLigaDB football schedule integration once the acceptable request cadence, selected leagues and attribution obligations are confirmed. Cricsheet warrants a separate date-only historical proposal if its published access and update limits can be established. Both require a separate review before any public evidence is displayed.
