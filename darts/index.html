02 · MODEL METHODOLOGY

How D1 calculates

Baseline uses sequential historical match results to update a player's Elo strength. For the match winner, its expected chance is:

P(A wins) = 1 / (1 + 10^((Rᵦ − Rₐ) / 400))

Rating changes follow K × (actual result − expected result), with K = 24. Same-date results are grouped to avoid artificial within-day ordering; the research score requires at least eight previous matches per player.

Not yet modelled: three-dart averages, checkout rates, throwing-first advantage, leg/set format and match-specific injuries. Those require verified historical inputs and controlled ablation tests.

03 · DATA INTEGRITY

No fabricated live data

The published feed includes a bounded sample of provider fixtures and results. D1 uses the 28-day aggregate when the match time and player IDs agree.

Research access: Darts API documentation. This provider requires an API key and restricts free results to a delayed window. Its odds are not verified executable prices.

Imported local data are not independently verified. They may be used to explore mathematics, never to qualify bets.
